# Практика 3 — Объектно-ориентированное программирование

Практический проект по курсу «ООП и другие полезные вещи» в рамках программы «Прикладной искусственный интеллект» (Яндекс Практикум / УрФУ).

## Тематические блоки

В данном репозитории реализованы задачи по ключевым темам ООП на Python:

1. **`01_bacteria/bacteria.py` — Объекты и классы:**
   - Симулятор популяции бактерий `BacteriaProducer`.
   - Инкапсуляция атрибутов `max_bacteria` и `current_bacteria_count`.
   - Методы `create()` и `delete()` с контролем переполнения и опустошения популяции.

2. **`02_store/products.py` — Принципы ООП и полиморфизм:**
   - Базовый класс товара `Product`.
   - Дочерние специализированные классы `Kettlebell` (спортивные гири) и `Clothing` (одежда).
   - Переопределение метода `get_full_info()` с вызовом `super().get_basic_info()`.

3. **`03_exceptions/date_validator.py` — Исключения и валидация данных:**
   - Обработка некорректных форматов дат рождения в исторических амбарных книгах.
   - Использование `try/except` для отлова `ValueError` из `datetime.strptime`.
   - Сбор статистики корректных и некорректных записей (`process_people`).

4. **`04_advanced/generators.py` — Расширенные возможности:**
   - Реализация функции-генератора `fibonacci(n)` с использованием ключевого слова `yield`.
   - Эффективная итерация по последовательности без загрузки всех чисел в оперативную память.

## Запуск тестов и линтеров

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов
pytest -v

# Проверка стиля кода
flake8 .
```
